# 🎄 크리스마스 눈싸움 3D

누구나 브라우저로 접속해서 함께 노는 **크리스마스 3D 오픈월드 눈싸움**입니다.
서버 하나가 하나의 월드이고, 접속한 모든 사람이 같은 눈마을과 설원에서 함께 몬스터를 물리칩니다.
PC(키보드·마우스)와 스마트폰(터치 조이스틱) 모두 지원합니다.

## 게임 소개

- 눈마을 밖 설원에 **필드 몬스터 75마리**가 돌아다닙니다. 마을에서 멀어질수록 강해집니다.
  - 눈밭(가까운 곳): 눈사람, 펭귄 · 숲(중간): 나쁜 루돌프 추가 · 먼 설원: 나쁜 산타 추가
  - 몬스터가 쓰러지면 **20초 뒤 같은 자리에서 다시 나타납니다** (바로 옆에 사람이 있으면 잠깐 미룸)
  - 나쁜 루돌프: 빠르게 달려들어 빨간 눈덩이를 빠르게 던짐 · 나쁜 산타: 석탄 눈덩이 3발 부채꼴
  - 나쁜 산타를 쓰러뜨리면 **황금 선물 2개를 떨어뜨림** (30초 안에 주우면 버프 + 80점)
- **👕 캐릭터 꾸미기**: 시작 화면이나 ⚙️ 설정에서 열기. 캐릭터 6종(요정·꼬마 산타·눈사람·펭귄·루돌프·진저브레드), 머리 9종(루돌프 머리띠·산타 모자·왕관·실크햇 등), 눈 7종(안경·선글라스·하트·별·외눈 안경·윙크), 코 5종(루돌프 코·당근 코·황금 코·반창고), 입 6종(산타 수염·콧수염·메롱·사탕·깜짝 입), 귀 6종(요정·곰·토끼·고양이 귀·방울 귀걸이), 목 4종, 등 4종(선물 자루·망토·천사 날개), 옷 색 6가지. 게임 중에 바꿔도 다른 사람 화면에 바로 반영
- 마을의 **초록 원(안전지대)** 밖에서는 플레이어끼리도 눈싸움(PvP)을 할 수 있습니다. 쓰러뜨리면 +200점.
- 근거리 **보이스 채팅**: 마이크 없이도 듣기 가능, 말하기는 설정에서 켜기. 플레이어별 음소거/차단.
- 맵 곳곳의 선물 상자 36개(먹으면 10초 뒤 다른 곳에 새로 생김) 13종
  - 기본: 체력 회복 · 트리플 샷 · 왕눈덩이 · 스피드 · 공격력 · 연사(최대 눈덩이 수도 늘어남) · 보호막(15초) · 무한 눈덩이
  - 공격형: 관통(여러 마리 뚫기) · 폭발(주변 몬스터도 피해) · 얼음(맞은 대상 느려짐) · 저격(사거리·속도↑) · 연발(한 줄 더 발사)
  - **보호막을 뺀 모든 효과는 시간 제한 없이 쓰러질 때까지 유지되고, 먹을수록 중첩**됩니다 (항목별 최대 단계 있음)
- 힐팩 32개: +35 회복, 10초 뒤 다시 생김
- 마을 중앙의 대형 모닥불(양옆에 작은 크리스마스트리 2그루): 옆에서 가만히 쉬면 체력이 빠르게 회복
- 🪑 앉기(F): 모닥불 근처에서 통나무 의자에 앉기 (6개 의자 × 2자리), 앉아서 쉬면 바로 회복 시작
- ☕ 티타임(T): 안전지대에서 머그컵에 담긴 커피를 마시는 동작, 앉은 채로도 가능 (다른 플레이어에게도 보임)
- 마을은 안전지대: 적이 들어오지 못하고 체력과 눈덩이가 회복됩니다.
- 채팅(Enter), 접속자 순위표, 미니맵, 징글벨 배경음악(M)

## 내 컴퓨터에서 실행

Node.js 18 이상만 있으면 됩니다. 설치할 패키지는 없습니다.

```bash
node server.js
```

브라우저에서 http://localhost:3000 을 엽니다. 같은 와이파이의 다른 기기에서는 `http://(내 컴퓨터 IP):3000` 으로 접속할 수 있습니다.

## 인터넷에 공개하기 (Render 무료 플랜)

1. 이 폴더를 GitHub 저장소에 올립니다.
2. https://render.com 에 GitHub 계정으로 가입합니다.
3. **New → Blueprint** 를 누르고 이 저장소를 고르면 `render.yaml` 설정대로 서버가 만들어집니다.
   (또는 **New → Web Service** → 저장소 선택 → Start Command 에 `node server.js`)
4. 배포가 끝나면 `https://(서비스이름).onrender.com` 주소가 생깁니다. 이 주소를 친구들에게 보내면 끝!

> 무료 플랜은 15분 동안 아무도 접속하지 않으면 서버가 잠듭니다. 다음 사람이 접속할 때 깨어나는 데 30초~1분 정도 걸리고, 그동안 월드 상태(몬스터, 점수)가 초기화됩니다. 항상 켜두려면 유료 플랜(Starter)을 쓰세요.

### 대기 화면과 잠들지 않게 하기

- **대기 화면 (GitHub Pages)**: `docs/index.html` 이 우리 디자인의 대기 화면입니다. 서버 `/health` 를 2초마다 확인하다가 준비되면 게임으로 자동 이동합니다.
  - 켜는 법: GitHub 저장소 → Settings → Pages → Source: *Deploy from a branch*, Branch: `main` / `/docs` → Save
  - 주소: `https://dawoo0427.github.io/christmas-snowball/` (친구들에게는 이 주소를 공유)
- **잠들지 않게 하기**
  - UptimeRobot(무료)에서 `https://christmas-snowball.onrender.com/health` 를 5분 간격 HTTP 모니터로 등록
  - 보조로 `.github/workflows/keepalive.yml` 이 10분마다 같은 주소를 호출합니다 (GitHub 사정에 따라 몇 분 늦어질 수 있음)
  - Render 무료 플랜은 한 달 750시간까지라 서버 1개를 계속 켜 둬도 범위 안입니다

## 설정 (환경 변수)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 3000 | 서버 포트 (호스팅 업체가 자동으로 넣어줌) |
| `SERVER_NAME` | 눈마을 1서버 | 화면에 보이는 서버 이름 |
| `MAX_PLAYERS` | 60 | 최대 동시 접속자 수 |
| `TURN_KEY_ID` | (없음) | Cloudflare Realtime TURN 키 ID. 보이스 채팅 중계용 |
| `TURN_KEY_API_TOKEN` | (없음) | Cloudflare Realtime TURN API 토큰. **절대 코드에 넣지 말고 환경변수로만** |

TURN 키가 없으면 보이스 채팅은 기기끼리 직접 연결만 시도합니다(일부 모바일·회사 네트워크에서는 연결 실패).
키가 있으면 서버가 `/turn` 에서 24시간짜리 임시 자격 증명을 발급해 브라우저에 전달하고, 키 자체는 브라우저로 나가지 않습니다.

## 폴더 구조

```
server.js          게임 서버 (웹페이지 제공 + WebSocket + 적 AI·판정)
shared/world.js    서버와 브라우저가 함께 쓰는 지형·배치·충돌 코드
public/index.html  게임 화면 (Three.js)
public/lib/        Three.js r149 (MIT 라이선스)
render.yaml        Render 배포 설정
old/               이전 버전들 (2D 버전, 1인용 3D 버전 등)
```

## 기술 메모

- 서버는 Node.js 기본 모듈만 사용합니다. WebSocket도 직접 구현했습니다.
- 서버가 30Hz로 적 AI·눈덩이·몬스터 리젠을 계산하고, 15Hz로 근처 상황을 각 플레이어에게 보냅니다.
- 플레이어 이동과 "내가 맞았는지"는 각자의 브라우저가 판정합니다(반응성 우선).
- 내 눈덩이가 적·상대에게 맞으면 내 화면이 서버에 명중을 신고하고, 서버가 거리만 확인해 바로 적용합니다. 화면에서 맞았는데 피해가 안 들어가는 "씹힘"을 막기 위한 방식입니다.
- 40명 동시 접속 테스트에서 플레이어 1명당 약 36KB/s 를 사용했습니다.
